# Changelog / Historial de cambios

## v2.0.1 — First public release / Primera versión pública

- Four interactive screens and 24 iRacing control actions. / Cuatro pantallas y 24 acciones de iRacing.
- Native dynamic Auto Fuel status and availability. / Estado y disponibilidad de Auto Fuel mediante telemetría nativa.
- Live telemetry, pit strategy, flags, fuel warnings and Night Monitor. / Telemetría, estrategia de boxes, banderas, alertas de combustible y monitor nocturno.
- Spanish installation manual and optional profile synchronization script. / Manual en español y sincronizador opcional de perfiles.

Earlier versions (1.1–2.0) were development builds, not public releases. / Las versiones anteriores fueron de desarrollo, no publicaciones públicas.
